# Subject2 — 中国大陆科目二 / 科目三 3D 模拟驾驶

浏览器端 3D 驾考训练项目，技术栈为 **React + TypeScript + Three.js / React Three Fiber**，目标是在 GitHub Pages 直接运行，并以车内第一人称完成科目二、科目三训练与模拟考试。

- 科目二：倒车入库、侧方停车、坡道定点停车和起步、曲线行驶、直角转弯入口。
- C2 自动隐藏坡道项目。
- 科目二组合模拟考试入口。
- 科目三综合道路训练 / 模拟考试入口。
- 第一人称 Three.js 道路与驾驶舱；驾驶位已调整为左侧真实观察位置；支持 M 键循环切换第一/第二/第三人称及垂直俯视视角，检查整车、四轮位置与行驶轨迹。
- 白天 / 夜间环境。
- 基础车辆运动模型。
- C1：油门、制动、方向盘、离合、1–5/N/R；C2：无离合 D/N/R；驻车制动器与点火。
- 左/右转向灯、双闪、近光灯、远光灯、双频喇叭；近远光会实际照亮 3D 场景。

- 三块实时 RenderTarget 左/右/中央后视镜；方向盘、挡杆、踏板、仪表与灯光状态联动。
- HUD、基础规则事件、成绩单。
- 驾驶轨迹复盘、扣分时间轴、扣分前后操作切片、优先改进习惯与证据定位。
- 复盘结果可一键回练证据项目；“车身边线控制”“观察与信号”支持跨项目专项训练包、阶段进度、训练包总复盘以及同一考生/准驾车型下的跨轮次改善趋势；训练中心会据此生成可解释的长期训练建议和最多两个不同训练包组成的今日训练计划，避免反复只刷同一类能力。

> 当前版本已越过 P0 骨架阶段：科目二项目状态机、连续考试、真实驾驶舱与三镜、科目三数据化路线、动态交通/碰撞、规则矩阵、C1/C2 全路线物理回归和轨迹复盘均已落地。当前开发重点是浏览器/WebGL 稳定性、P4 动态交通精修与 P5 完整评判/复盘体验。

### 方向盘模型

方向盘使用渐进键盘转向模型：短按用于微调，持续按住会逐步提高打轮速度，并根据车速约束转向响应；松键后按模型回正，A+D 可快速居中。方向盘圈数、打轮速度、回正和前轮最大转角由 `src/rules/drivingRules.ts` 与 `src/input/keyboardSteering.ts` 共同约束。

## 本地运行

```bash
npm install
npm run dev
```

生产构建与回归：

```bash
npm test
npm run build
npx playwright install chromium   # 首次运行浏览器 E2E 时
npm run test:e2e
```

`npm run test:e2e` 会启动生产预览，并用 Chromium + WebGL2 smoke 覆盖首屏、科二/科三 3D 场景、四视角、基础驾驶控制、结果/复盘入口、长期/今日训练建议以及跨项目专项训练包的双场景切换。GitHub Pages 发布也受同一浏览器闸门保护。

## 规则基线

规则设计以中国大陆现行机动车驾驶人考试制度为基线，重点参考：

- 《机动车驾驶证申领和使用规定》（公安部令第 172 号）。
- GA 1026-2022《机动车驾驶人考试内容和方法》。

C1 科目二模型包含倒车入库、坡道定点停车和起步、侧方停车、曲线行驶、直角转弯；C2 不包含坡道项目。科目三模型按上车准备、起步、直线行驶、加减挡位、变更车道、靠边停车、直行通过路口、路口转弯、通过人行横道线、学校区域、公共汽车站、会车、超车、掉头、夜间行驶等能力组织。

全国规则与地方考场数据会分层：核心引擎不硬编码某一个城市的考试路线。实际考场布局、设备阈值和地方执行细节可能不同，模拟成绩不具有真实机动车驾驶人考试效力。

## 部署

Vite 生产构建使用相对资源基址 `./`，因此同一份 `dist` 可部署在 GitHub Pages 仓库子路径，也可直接部署到一级自定义域名根路径（例如 `https://kemu2.aben.io/`），构建后的 CSS / JS 不依赖 `/Subject2/` 绝对前缀。

工作流位于 `.github/workflows/pages.yml`。发布链路为：Node 回归 → TypeScript/Vite build → Chromium/WebGL2 E2E smoke → Pages artifact → deploy。浏览器 smoke 失败时不会部署，并会上传 Playwright report、trace、截图/视频等失败证据。仓库首次发布时请在 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**。
