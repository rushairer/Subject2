# Subject2 — 中国大陆科目二 / 科目三 3D 模拟驾驶

浏览器端 3D 驾考训练项目，技术栈为 **React + TypeScript + Three.js / React Three Fiber**，目标是在 GitHub Pages 直接运行，并以车内第一人称完成科目二、科目三训练与模拟考试。

## 已实现的第一阶段

- 考生姓名、性别、年龄、C1/C2 档案。
- 科目二：倒车入库、侧方停车、坡道定点停车和起步、曲线行驶、直角转弯入口。
- C2 自动隐藏坡道项目。
- 科目二组合模拟考试入口。
- 科目三综合道路训练 / 模拟考试入口。
- 第一人称 Three.js 道路与驾驶舱；驾驶位已调整为左侧真实观察位置；支持 M 键循环切换第一/第二/第三人称视角检查整车与行驶轨迹。
- 白天 / 夜间环境。
- 基础车辆运动模型。
- C1：油门、制动、方向盘、离合、1–5/N/R；C2：无离合 D/N/R；驻车制动器与点火。
- 左/右转向灯、双闪、近光灯、远光灯、双频喇叭；近远光会实际照亮 3D 场景。
- 左右观察与回头观察。
- 三块实时 RenderTarget 左/右/中央后视镜；方向盘、挡杆、踏板、仪表与灯光状态联动。
- HUD、基础规则事件、成绩单。
- GitHub Pages Actions 部署。

> 当前版本是可驾驶的 P0 骨架。项目最终目标不是“网页小 Demo”，而是数据驱动的驾考训练系统：科二精确场地、真实镜面、科三完整路线、交通参与者 AI、突发事件、语音指令、逐项判定和轨迹复盘都在后续里程碑内。

## 键位

| 操作 | 键位 |
| --- | --- |
| 油门 / 制动 | W / S |
| 左 / 右打方向盘 | A / D（按住持续打轮，松开保持当前角度，不自动回正） |
| 离合器 | C |
| 1–5 挡 | 1–5 |
| 空挡 / 倒挡 | N / R |
| 驻车制动器 | Space |
| 点火 / 熄火 | I |
| 左 / 右转向灯 | Q / E |
| 危险报警闪光灯 | V |
| 近光 / 远光 | L / K |
| 左 / 右观察 | Z / X（按住） |
| 回头观察 | F（按住） |
| 视角循环 | M：第一人称 → 第二人称（车前侧观察）→ 第三人称（车后上方跟随） |

### 方向盘模型

方向盘采用累计打轮模型：默认约 2.7 圈锁到锁，中心到单侧极限约 1.35 圈。按住 A/D 持续向左/右打轮，松开后保持当前方向盘位置；回正必须主动向相反方向打轮。方向盘圈数、打轮速度和前轮最大转角均由 `src/rules/drivingRules.ts` 配置。

## 规则基线

规则设计以中国大陆现行机动车驾驶人考试制度为基线，重点参考：

- 《机动车驾驶证申领和使用规定》（公安部令第 172 号）。
- GA 1026-2022《机动车驾驶人考试内容和方法》。

C1 科目二模型包含倒车入库、坡道定点停车和起步、侧方停车、曲线行驶、直角转弯；C2 不包含坡道项目。科目三模型按上车准备、起步、直线行驶、加减挡位、变更车道、靠边停车、直行通过路口、路口转弯、通过人行横道线、学校区域、公共汽车站、会车、超车、掉头、夜间行驶等能力组织。

全国规则与地方考场数据会分层：核心引擎不硬编码某一个城市的考试路线。实际考场布局、设备阈值和地方执行细节可能不同，模拟成绩不具有真实机动车驾驶人考试效力。

## 路线图

1. **P0 可驾驶骨架**：第一人称、车辆输入、章节、考试会话、成绩单、Pages。
2. **P1 科目二完整化**：五类场地精确几何、项目状态机、压线/停车/时限/距离检测、C1/C2 规则。
3. **P2 驾驶舱真实性**：真正的 RenderTarget 左/右/内后视镜、方向盘/踏板/挡杆动画、仪表与灯光。
4. **P3 科目三道路系统**：3 km+ 数据化考试路线、标志标线、路口、学校、公交站、限速与考试语音。
5. **P4 动态交通**：NPC 汽车、行人、自行车/电动车，横穿、加塞、急停等突发事件。
6. **P5 完整评判与复盘**：逐条规则、轨迹回放、时间轴、错误定位、训练建议。
7. **P6 考场包**：支持按城市/驾校/考场复刻真实场地与路线，同时保持全国规则基线独立。
